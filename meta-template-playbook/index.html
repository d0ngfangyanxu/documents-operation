WhatsApp 模板如何做得更能转化

把模板能力拆成“看见、理解、行动、闭环”四步：用媒体或商品卡抢首屏，用个性化正文解释理由，用按钮缩短路径，用目录、优惠码或 Flow 承接转化。

先按转化路径理解模板

不要先想“能放几个按钮”，先想用户看到消息后的下一步。模板的每个组件都应该服务一个动作。

01 看见

视觉抓注意

图片、视频、商品卡、倒计时，让用户第一眼知道这条消息和自己有关。

02 理解

正文讲理由

用姓名、品类、金额、时间、优惠码变量，说清楚为什么现在行动。

03 行动

按钮少而准

URL、Copy Code、View、Quick Reply、Phone、Flow 只保留最关键下一步。

04 闭环

减少跳出

能在 WhatsApp 内完成就用 View、SPM、MPM、Flow；必须跳站时 URL 带好追踪参数。

模板组件能做什么

Meta 官方把模板拆成 header、body、footer、buttons。唯一必需的是 body，其余按目标组合。

能力官方边界转化价值
文本 Header1 个 / 60 字符 / 支持 1 个参数首屏点题：优惠截止、订单号、活动主题
媒体 Headerimage、video、GIF、document；媒体先上传并用 header_handle 引用用图片或短视频抢注意力，用 PDF/票据/报价单增强信任
位置 HeaderUtility/Marketing 可用；点击打开默认地图；不支持实时位置门店、配送、取货、预约到店
Body必需；最多 1024 字符；支持多个变量姓名、金额、商品、优惠码、时间都放在这里做个性化
Footer可选；最多 60 字符；限时优惠模板不支持 footer退订、客服提示、轻量补充说明
Buttons最多 10 个；不同按钮类型另有限制把用户带到下一步：买、复制、咨询、填表、拨号

按钮玩法决策表

按钮越多不一定越好。超过 3 个按钮会出现折叠；4 个以上按钮或 Quick Reply 与其他按钮混用时，桌面端可能不能直接查看。

按钮类型官方限制 / 行为建议用法
URL最多 2 个；打开默认移动浏览器；URL 最多 2000 字符；支持 1 个尾部变量商品页、支付页、预约页；变量带 coupon、sku、utm
Quick Reply最多 10 个；点击后向商家发送按钮文本；混用时需分组“我要优惠”“咨询尺码”“不再接收”，用于轻交互和意向分层
Copy Code最多 1 个；点击复制发送时定义的文本；示例值最多 20 字符优惠码、推荐码、营销码
Phone Number最多 1 个；点击拨号；标签最多 25 字符，号码最多 20 字符高客单价、B2B、人工确认订单
Voice Call点击后发起 WhatsApp call 给商家即时咨询，比电话按钮更像聊天内动作
FLOW模板中可用 FLOW 按钮；按钮文字最多 25 字符问卷、报价、预约、资格判断、偏好收集
SPM / MPM商品目录专用按钮；从目录拉商品信息留在 WhatsApp 内看商品、加购、下单
!
视觉上建议把主 CTA 控制在 1-2 个。需要多意图收集时，优先用 Quick Reply 或 Flow，而不是堆满 URL、电话和回复按钮。

高转化视觉组件

下面把官方示例图和玩法放在一起看：每一种视觉组件背后都对应不同的转化场景。

抢首屏

媒体 Header

模板顶部的视觉位，适合新品、折扣、强视觉 SKU、服务前后对比、报价单或票据。

  • 图片/短视频先讲“为什么现在点开”
  • 配合 URL 或 Copy Code，把注意力直接导向行动
多卖点种草

Media / Interactive Carousel

最多 10 张媒体卡，每张卡可以是一张图或视频，适合多 SKU、多套餐、卖点拆解。

  • 每张卡只讲一个卖点
  • URL 到对应 SKU，Quick Reply 承接“帮我选”
目录闭环

Product Card Carousel

从 Catalog 拉商品图、标题和价格。View 按钮可留在 WhatsApp 内看详情、加购、提交订单。

  • 目录完整时优先 View，减少跳转摩擦
  • 需要复杂 checkout 时改用 URL
商品召回

SPM / MPM

SPM 适合单品补货、浏览未购；MPM 适合购物车召回、套装清单和节日选品。

  • SPM 用一个强理由推动下单
  • MPM 用分组降低选择成本
紧迫感

Limited-Time Offer / Coupon

限时优惠可显示过期时间和倒计时，优惠码模板可直接 Copy Code，再接 URL。

  • “倒计时 + 复制码 + 去使用”是一条完整转化链
  • Web/Desktop 对限时优惠支持有限，需考虑移动端体验

推荐组合例子

可以直接作为模板 brief 使用：组件组合、正文方向和适用场景都放在一张卡里。

01

限时优惠爆发

image/video header + 个性化 body + Limited-Time Offer + Copy Code + URL

例子：Hi {{name}}，你浏览过的 {{category}} 今天 22:00 前 25% off。复制码 SAVE25，点“立即使用”。

适合：促销、弃购、节日档

02

留在 WhatsApp 内下单

Product Card Carousel + View

例子：给你挑了 5 个适合 {{use_case}} 的款式，卡片展示商品，用户点 View 加购。

适合：目录完整、低客单、冲动购买

03

内容种草到官网

Media Card Carousel + URL + Quick Reply

例子：每张卡一个卖点视频/图，URL 到对应 SKU；Quick Reply 是“帮我选”。

适合：官网 checkout 更强、需要 upsell/cross-sell

04

高意向筛选

Body + FLOW button

例子：30 秒帮你匹配方案，Flow 内收集预算、偏好、地区、时间，完成后转客服或报价。

适合：教育、保险、医美、SaaS、B2B 线索

05

单品召回

SPM + 个性化 body + View

例子：{{name}}，你看过的这款补货了。今天下单可用 {{code}}。

适合：浏览未购、降价、补货、库存低

06

购物车召回

MPM + 分组 + 折扣变量

例子：Header 提醒购物车，Body 放折扣码，View items 展示多个商品和套装。

适合：多商品弃购、搭配购买

07

线下转化

Location header + body + Quick Reply/Phone

例子：门店活动、预约到店、配送中；地图打开导航，Quick Reply 做改期/联系客服。

适合：门店、到店预约、本地服务
